## How to Write the IMG File

Follow these steps carefully.

> **Warning:** Writing the IMG file will erase the selected USB pen drive or micro SD card. Make sure you select the correct storage device before writing.

---

## Installation Steps

### Step 1: Download IMG

Click the download link and save the **Pappu Node IMG** file to your Windows computer.

Download link:

```text
http://49.12.79.141:5259/pappu-node-v2.img
```

---

### Step 2: Open Rufus or Win32 Disk Imager

Use one of the following tools on your Windows computer:

- Rufus
- Win32 Disk Imager

---

### Step 3: Select Storage

Choose your storage device:

- Minimum 16GB USB pen drive

or

- Minimum 16GB Class 10 micro SD card

Then write the IMG file to the selected storage device.

---

### Step 4: Boot Raspberry Pi

Insert the prepared storage into your **Raspberry Pi 3 Model B**.

Then power on the device.

---

### Step 5: Connect HDMI & Scan QR Code

Connect an HDMI cable to the Raspberry Pi HDMI port.

When the boot process completes, a **QR code** will appear on the screen.

Scan the QR code using your phone.

---

### Step 6: Activate & Start Mining

After scanning the QR code:

1. Enter your activation code.
2. Login or register your account.
3. Add the node to your account.
4. Connect the device to the internet.

Once the internet is connected, the node will go live and start mining.

## First Boot Activation Process

After writing the IMG file and booting the Raspberry Pi:

1. Insert the prepared USB pen drive or micro SD card into the Raspberry Pi.
2. Connect the HDMI cable to the Raspberry Pi HDMI port.
3. Connect the Raspberry Pi to power.
4. Wait until the boot process is completed.
5. A QR code will appear on the HDMI display.
6. Scan the QR code using your phone.
7. Enter your activation code.
8. Login or register your Pappu Mining account.
9. Add the node to your account.
10. Connect the device to the internet.
11. The node will go live and start mining.

---

## Safety Notice

Always confirm that you selected the correct USB pen drive or micro SD card before writing the IMG file.

The writing process will remove all existing data from the selected storage device.

Do not write the IMG file to a storage device that contains important files.

## Troubleshooting

### QR Code Not Showing

Check the following:

- HDMI cable is properly connected.
- Display or monitor is powered on.
- Raspberry Pi is receiving proper power.
- IMG file was written correctly.
- Correct storage device is inserted.

### Device Not Booting

Check the following:

- You are using Raspberry Pi 3 Model B.
- Storage is minimum 16GB.
- Micro SD card is Class 10 or better.
- IMG file was written using Rufus or Win32 Disk Imager.
- Power adapter is stable and suitable for Raspberry Pi.

### Node Not Going Live

Check the following:

- Internet connection is active.
- Activation code is correct.
- Node is added to your Pappu Mining account.
- Device has completed the boot process.
- QR code activation was completed successfully.
